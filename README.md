# Study Notes — Free GitHub Pages Website

1. GitHub पर Public repository बनाएं।
2. इस ZIP की सारी files repository में upload करें।
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. GitHub Pages आपका free website address देगा।

HTML files इन folders में रखें:
- English/Verb
- English/Idioms
- English/Vocabulary
- Haryana-GK
- Maths
- Reasoning

नई HTML file को Home page पर दिखाने के लिए index.html में उसका card/link जोड़ना होगा।
